# 小猫起卦 · 喵星测格

一个结合八卦和五行的趣味性格测试小游戏。

## 在线体验

[点击这里开始测试](https://你的链接.netlify.app)

## 本地运行

直接双击 `index.html` 即可在浏览器中打开。

## 功能特色

- 🐱 可爱猫咪主题
- ☯️ 八卦 × 五行 性格测评
- 🎴 8 种本命格 + 5 种当运色
- 💕 配对系统（生克关系）
- ✨ 变爻 + 归位稀有彩蛋

## 部署说明

本项目为纯静态页面，可部署到任何静态托管服务：

- **Netlify Drop**: https://app.netlify.com/drop （拖拽文件夹即可）
- **GitHub Pages**: 推送到仓库后在 Settings → Pages 开启
- **Vercel**: 导入仓库自动部署

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript
- 无后端依赖
